ShutterLink 소개 지원 개인정보 처리방침 English

개인정보 처리방침

시행일: 2026년 10월 3일 · 적용 대상: ShutterLink (iPhone 앱), ShutterLink Remote (App Clip)

요약

ShutterLink는 어떤 개인정보도 수집하거나 외부로 보내지 않습니다. 개발자가 운영하는 서버가 없고, 계정도 없으며, 분석·광고·추적 도구를 쓰지 않습니다. 촬영한 사진과 동영상은 촬영한 iPhone의 사진 보관함에만 저장되고, 두 iPhone은 Bluetooth로 서로 직접 통신합니다.

1. 기기끼리 주고받는 정보

카메라 iPhone(ShutterLink)과 리모컨 iPhone(ShutterLink Remote)은 Bluetooth Low Energy로 가까운 거리에서 직접 연결됩니다. 인터넷이나 제3자 서버를 거치지 않습니다.

방향내용용도
리모컨 → 카메라4자리 연결 코드, 셔터·녹화·타이머·줌·카메라 전환 명령연결 확인과 촬영 조작
카메라 → 리모컨촬영 모드, 녹화 시간, 타이머, 줌 배율 같은 상태 값리모컨 화면에 상태 표시
카메라 → 리모컨저해상도 미리보기 영상 (카메라에 비치는 장면)리모컨에서 구도 확인

미리보기 영상은 연결된 동안 실시간으로만 보내고, 리모컨 쪽은 이를 저장하지 않습니다. 연결 코드는 앱을 실행할 때마다 새로 만들어지며, 코드를 아는 리모컨만 명령과 미리보기를 받을 수 있습니다.

2. 요청하는 권한

  • 카메라 (ShutterLink) — 사진과 동영상을 찍기 위해 필요합니다.
  • 마이크 (ShutterLink) — 동영상에 소리를 함께 녹음하기 위해 필요합니다.
  • 사진 보관함에 추가 (ShutterLink) — 찍은 사진과 동영상을 저장하기 위해 필요합니다. 추가 전용 권한이라 기존 사진을 읽지 않습니다.
  • Bluetooth (ShutterLink, ShutterLink Remote) — 두 iPhone을 연결하기 위해 필요합니다.

권한은 언제든 iPhone의 설정 앱에서 끌 수 있습니다. 끄면 해당 기능만 동작하지 않습니다.

3. 기기에 저장되는 정보

ShutterLink가 저장하는 것은 사용자가 찍은 사진과 동영상뿐이며, 촬영한 iPhone의 사진 보관함에 저장됩니다. 그 밖에는 앱을 연 횟수와 처음 설치한 날 같은 몇 가지 값만 기기 안에 기록하며, 이 값은 기기 밖으로 나가지 않습니다. ShutterLink Remote는 아무것도 저장하지 않습니다.

4. App Clip

ShutterLink Remote는 App Clip이라 QR 코드를 스캔하면 설치 없이 열립니다. App Clip을 내려받는 과정은 Apple이 처리하며 Apple 개인정보 처리방침을 따릅니다. QR 코드에 담긴 주소에는 4자리 연결 코드만 들어 있습니다.

5. 이 웹사이트

소개·지원·개인정보 처리방침 페이지는 GitHub Pages에서 호스팅됩니다. 페이지를 열 때 GitHub이 접속 기록(IP 주소 등)을 처리할 수 있으며, 이는 GitHub 개인정보 처리방침을 따릅니다. 이 사이트는 쿠키나 분석 스크립트를 쓰지 않습니다.

6. 아동의 개인정보

앱은 누구의 개인정보도 수집하지 않으므로 아동의 개인정보도 수집하지 않습니다.

7. 변경

이 방침이 바뀌면 이 페이지를 고치고 위의 시행일을 갱신합니다. 앱이 정보를 수집하게 되는 변경이라면 시행 전에 이 페이지와 앱 업데이트 설명에 알립니다.
