มีผลตั้งแต่ 16 ตุลาคม 2026 · ใช้กับ ShutterLink (แอป iPhone) และรีโมต ShutterLink (App Clip)

สรุป

ShutterLink ไม่เก็บข้อมูลส่วนบุคคล เช่น ชื่อ ข้อมูลติดต่อ ตำแหน่งที่ตั้ง หรือภาพถ่าย ผู้พัฒนาไม่มีเซิร์ฟเวอร์ ไม่มีบัญชี และไม่มีเครื่องมือโฆษณาหรือติดตามใด ๆ ภาพถ่ายและวิดีโอที่คุณถ่ายจะบันทึกลงคลังรูปภาพของ iPhone ที่ถ่ายเท่านั้น และ iPhone ทั้งสองเครื่องสื่อสารกันโดยตรงผ่าน Bluetooth เพื่อดูว่ามีอุปกรณ์ใช้แอปกี่เครื่องและแก้ไขข้อบกพร่อง แอปส่งเพียงสถิติการใช้งานแบบไม่ระบุตัวตนและรายงานการหยุดทำงานไปยัง Apple iCloud (หัวข้อที่ 4)

1. สิ่งที่ iPhone ทั้งสองเครื่องแลกเปลี่ยนกัน

iPhone ตัวถ่ายภาพ (ShutterLink) และ iPhone ตัวรีโมต (รีโมต ShutterLink) เชื่อมต่อกันโดยตรงผ่าน Bluetooth Low Energy ในระยะใกล้ ไม่มีข้อมูลผ่านอินเทอร์เน็ตหรือเซิร์ฟเวอร์ของบุคคลที่สาม

ทิศทางเนื้อหาวัตถุประสงค์
รีโมต → กล้องรหัสจับคู่ 4 หลัก คำสั่งชัตเตอร์ บันทึก ตั้งเวลา ซูม และสลับกล้องยืนยันการเชื่อมต่อและควบคุมการถ่ายภาพ
กล้อง → รีโมตค่าสถานะ เช่น โหมดถ่ายภาพ เวลาบันทึก ตัวตั้งเวลา และระดับซูมแสดงสถานะบนรีโมต
กล้อง → รีโมตวิดีโอตัวอย่างความละเอียดต่ำ (สิ่งที่กล้องมองเห็น)จัดเฟรมภาพจากรีโมต

ภาพตัวอย่างจะสตรีมแบบเรียลไทม์เฉพาะตอนที่เชื่อมต่ออยู่ และรีโมตไม่เก็บไว้ รหัสจับคู่ใหม่จะถูกสร้างทุกครั้งที่เปิดแอป และมีเพียงรีโมตที่รู้รหัสเท่านั้นที่ส่งคำสั่งและรับภาพตัวอย่างได้

2. สิทธิ์การเข้าถึง

  • กล้อง (ShutterLink) — เพื่อถ่ายภาพและวิดีโอ
  • ไมโครโฟน (ShutterLink) — เพื่อบันทึกเสียงไปกับวิดีโอ
  • เพิ่มลงในรูปภาพ (ShutterLink) — เพื่อบันทึกภาพถ่ายและวิดีโอที่คุณถ่าย เป็นสิทธิ์แบบเพิ่มอย่างเดียว แอปจึงไม่อ่านภาพที่คุณมีอยู่เดิม
  • Bluetooth (ShutterLink และรีโมต ShutterLink) — เพื่อเชื่อมต่อ iPhone ทั้งสองเครื่อง

คุณปิดสิทธิ์เหล่านี้ได้ทุกเมื่อในแอปการตั้งค่าบน iPhone เฉพาะฟีเจอร์ที่ต้องใช้สิทธิ์นั้นเท่านั้นที่จะหยุดทำงาน

3. สิ่งที่เก็บไว้ในอุปกรณ์ของคุณ

เนื้อหาเดียวที่ ShutterLink บันทึกคือภาพถ่ายและวิดีโอที่คุณถ่าย ซึ่งจะบันทึกลงคลังรูปภาพของ iPhone ที่ถ่าย นอกจากนี้แอปเก็บค่าเล็กน้อยไว้ในอุปกรณ์ เช่น จำนวนครั้งที่เปิดแอปและเวลาที่ติดตั้งครั้งแรก ซึ่งใช้สำหรับสถิติการใช้งานแบบไม่ระบุตัวตนด้านล่างเท่านั้น รีโมต ShutterLink ไม่เก็บอะไรเลย

4. สถิติการใช้งานแบบไม่ระบุตัวตน

เพื่อทำความเข้าใจว่ามีผู้ใช้แอปกี่คนและแก้ไขข้อบกพร่อง ShutterLink ส่งสถิติแบบไม่ระบุตัวตนต่อไปนี้ไปยัง Apple iCloud (CloudKit) เฉพาะผู้พัฒนาเท่านั้นที่อ่านได้

  • ID สุ่มที่สร้างตอนติดตั้ง (ไม่เชื่อมโยงกับอุปกรณ์ Apple ID หรือแอปอื่น และเปลี่ยนไปเมื่อติดตั้งใหม่)
  • เวอร์ชันแอป เวอร์ชัน iOS และการตั้งค่าภูมิภาคและภาษา
  • จำนวนครั้งที่เปิดแอปและวันที่เปิด วันที่ติดตั้ง และจำนวนวันนับจากวันติดตั้ง
  • รายงานการแครชและการค้าง (เวอร์ชันแอป เวอร์ชัน iOS ประเภทอุปกรณ์ และรายละเอียดทางเทคนิคของข้อผิดพลาด)

ข้อมูลเหล่านี้ไม่มีชื่อ ข้อมูลติดต่อ ตำแหน่งที่ตั้ง ภาพถ่าย วิดีโอ หรือภาพสดอย่างเด็ดขาด และจะส่งเฉพาะเมื่อคุณลงชื่อเข้าใช้ iCloud รีโมต ShutterLink (App Clip) ไม่ส่งอะไรเลย

5. App Clip

รีโมต ShutterLink เป็น App Clip จึงเปิดได้โดยไม่ต้องติดตั้งเมื่อคุณสแกน QR code การดาวน์โหลด App Clip ดำเนินการโดย Apple ตามนโยบายความเป็นส่วนตัวของ Apple ที่อยู่ใน QR code มีเพียงรหัสจับคู่ 4 หลักเท่านั้น

6. เว็บไซต์นี้

หน้าเกี่ยวกับ การสนับสนุน และนโยบายความเป็นส่วนตัวโฮสต์บน GitHub Pages เมื่อคุณเปิดหน้าเว็บ GitHub อาจประมวลผลบันทึกการเข้าถึง เช่น ที่อยู่ IP ตามคำชี้แจงความเป็นส่วนตัวทั่วไปของ GitHub เว็บไซต์นี้ไม่ใช้คุกกี้หรือสคริปต์วิเคราะห์

7. ความเป็นส่วนตัวของเด็ก

แอปไม่เก็บข้อมูลส่วนบุคคลของใครทั้งสิ้น รวมถึงเด็กด้วย

8. การเปลี่ยนแปลง

หากนโยบายนี้เปลี่ยนแปลง เราจะอัปเดตหน้านี้และวันที่มีผลด้านบน หากการเปลี่ยนแปลงทำให้แอปเริ่มเก็บข้อมูล เราจะประกาศในหน้านี้และในบันทึกการอัปเดตของแอปก่อนที่จะมีผล

9. ติดต่อเรา

หากมีคำถามเกี่ยวกับความเป็นส่วนตัว โปรดเปิด issue ที่ GitHub Issues
