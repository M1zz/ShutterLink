隐私政策

2026 年 10 月 16 日生效 · 适用于 ShutterLink（iPhone App）和 ShutterLink 遥控器（App Clip）

概要

ShutterLink 不会收集你的姓名、联系方式、位置或照片等个人信息。开发者没有运营任何服务器，没有账号，也没有广告或跟踪工具。你拍摄的照片和视频只会存入拍摄用 iPhone 的相册，两台 iPhone 之间通过蓝牙直接通信。为了了解有多少设备在使用并修复错误，App 只会向 Apple iCloud 发送匿名的使用统计和崩溃报告（第 4 节）。

1. 两台 iPhone 之间交换的内容

拍摄用的 iPhone（ShutterLink）和遥控用的 iPhone（ShutterLink 遥控器）在近距离内通过低功耗蓝牙直接连接。数据不会经过互联网或任何第三方服务器。

方向内容用途
遥控器 → 相机4 位配对码；快门、录制、定时、变焦和切换相机的指令确认连接并控制拍摄
相机 → 遥控器拍摄模式、录制时长、定时和变焦倍数等状态值在遥控器上显示状态
相机 → 遥控器低分辨率预览视频（相机拍到的画面）在遥控器上取景

预览仅在连接期间实时传输，遥控器不会保存。每次启动 App 都会生成新的配对码，只有知道配对码的遥控器才能发送指令并接收预览。

2. 权限

  • 相机（ShutterLink）— 用于拍摄照片和视频。
  • 麦克风（ShutterLink）— 用于在视频中录入声音。
  • 添加到照片（ShutterLink）— 用于保存你拍摄的照片和视频。这是仅限添加的权限，App 不会读取你已有的照片。
  • 蓝牙（ShutterLink 和 ShutterLink 遥控器）— 用于连接两台 iPhone。

你可以随时在 iPhone 的“设置”App 中关闭其中任何一项，只有依赖它的功能会停止工作。

3. 保存在你设备上的内容

ShutterLink 保存的内容只有你拍摄的照片和视频，它们会存入拍摄用 iPhone 的相册。此外，App 还会在设备上记录少量数值，例如打开次数和首次安装的时间，仅用于下面的匿名使用统计。ShutterLink 遥控器不保存任何内容。

4. 匿名使用统计

为了了解有多少人在使用 App 并修复错误，ShutterLink 会向 Apple iCloud（CloudKit）发送以下匿名统计，只有开发者可以读取。

  • 安装时生成的随机 ID（与你的设备、Apple ID 或其他 App 均无关联，重新安装后会改变）
  • App 版本、iOS 版本，以及地区和语言设置
  • App 的打开次数和日期、安装日期以及安装后的天数
  • 崩溃和卡死报告（App 版本、iOS 版本、设备类型以及错误的技术细节）

其中绝不包含你的姓名、联系方式、位置、照片、视频或实时预览。只有登录 iCloud 时才会发送。ShutterLink 遥控器（App Clip）不会发送任何内容。

5. App Clip

ShutterLink 遥控器是一个 App Clip，扫描二维码即可免安装打开。App Clip 的下载由 Apple 依据 Apple 隐私政策处理。二维码中的地址只包含 4 位配对码。

6. 本网站

“关于”“支持”和“隐私政策”页面托管在 GitHub Pages 上。你打开页面时，GitHub 可能会依据 GitHub 通用隐私声明处理 IP 地址等访问日志。本网站不使用 Cookie 或分析脚本。

7. 儿童隐私

本 App 不收集任何人的个人信息，包括儿童的个人信息。

8. 变更

如果本政策有变更，我们会更新本页面及上方的生效日期。如果变更会使 App 开始收集信息，我们会在生效前于本页面和 App 的更新说明中公布。

9. 联系我们

如对隐私有任何疑问，请在 GitHub Issues 提交问题。
