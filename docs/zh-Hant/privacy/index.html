隱私權政策

2026 年 10 月 16 日生效 · 適用於 ShutterLink（iPhone App）和 ShutterLink 遙控器（App Clip）

摘要

ShutterLink 不會蒐集你的姓名、聯絡方式、位置或照片等個人資料。開發者沒有營運任何伺服器，沒有帳號，也沒有廣告或追蹤工具。你拍攝的照片和影片只會儲存到拍攝用 iPhone 的相簿，兩台 iPhone 之間透過藍牙直接通訊。為了了解有多少裝置在使用並修復錯誤，App 只會向 Apple iCloud 傳送匿名的使用統計和當機報告（第 4 節）。

1. 兩台 iPhone 之間交換的內容

拍攝用的 iPhone（ShutterLink）和遙控用的 iPhone（ShutterLink 遙控器）在近距離內透過低功耗藍牙直接連接。資料不會經過網際網路或任何第三方伺服器。

方向內容用途
遙控器 → 相機4 位數配對碼；快門、錄影、計時、變焦和切換鏡頭的指令確認連接並控制拍攝
相機 → 遙控器拍攝模式、錄影時間、計時和變焦倍率等狀態值在遙控器上顯示狀態
相機 → 遙控器低解析度預覽影片（相機拍到的畫面）在遙控器上取景

預覽僅在連接期間即時傳輸，遙控器不會儲存。每次啟動 App 都會產生新的配對碼，只有知道配對碼的遙控器才能傳送指令並接收預覽。

2. 權限

  • 相機（ShutterLink）— 用於拍攝照片和影片。
  • 麥克風（ShutterLink）— 用於在影片中收錄聲音。
  • 加入照片（ShutterLink）— 用於儲存你拍攝的照片和影片。這是僅限加入的權限，App 不會讀取你既有的照片。
  • 藍牙（ShutterLink 和 ShutterLink 遙控器）— 用於連接兩台 iPhone。

你可以隨時在 iPhone 的「設定」App 中關閉其中任何一項，只有仰賴它的功能會停止運作。

3. 儲存在你裝置上的內容

ShutterLink 儲存的內容只有你拍攝的照片和影片，它們會儲存到拍攝用 iPhone 的相簿。此外，App 還會在裝置上記錄少量數值，例如開啟次數和首次安裝的時間，僅用於下方的匿名使用統計。ShutterLink 遙控器不儲存任何內容。

4. 匿名使用統計

為了了解有多少人在使用 App 並修復錯誤，ShutterLink 會向 Apple iCloud（CloudKit）傳送以下匿名統計，只有開發者可以讀取。

  • 安裝時產生的隨機 ID（與你的裝置、Apple ID 或其他 App 皆無關聯，重新安裝後會改變）
  • App 版本、iOS 版本，以及地區和語言設定
  • App 的開啟次數和日期、安裝日期以及安裝後的天數
  • 當機和卡住報告（App 版本、iOS 版本、裝置類型以及錯誤的技術細節）

其中絕不包含你的姓名、聯絡方式、位置、照片、影片或即時預覽。只有登入 iCloud 時才會傳送。ShutterLink 遙控器（App Clip）不會傳送任何內容。

5. App Clip

ShutterLink 遙控器是一個 App Clip，掃描 QR code 即可免安裝開啟。App Clip 的下載由 Apple 依據 Apple 隱私權政策處理。QR code 中的網址只包含 4 位數配對碼。

6. 本網站

「關於」「支援」和「隱私權政策」頁面託管在 GitHub Pages 上。你開啟頁面時，GitHub 可能會依據 GitHub 一般隱私權聲明處理 IP 位址等存取記錄。本網站不使用 Cookie 或分析腳本。

7. 兒童隱私

本 App 不蒐集任何人的個人資料，包括兒童的個人資料。

8. 變更

如果本政策有變更，我們會更新本頁面及上方的生效日期。如果變更會使 App 開始蒐集資料，我們會在生效前於本頁面和 App 的更新說明中公告。

9. 聯絡我們

如對隱私權有任何疑問，請在 GitHub Issues 提出問題。
